# APERION PLANETAE README

###### CREATED BY DAVID SARGENT

  
## Background & Controls

Inspired by Atari Xevious, I stripped the lives, and made multiple planets for the player to go through in their single life.
Pruned some concepts from the build, since the Syllabus Contract needed adherence, some features were removed. Cut features are not marked on the draw.io board.
Try to find how many planets there are and enjoy the Infinite running of Planets you legendary Pilot!

- Move Ship - WASD | Arrow Keys;
- Fire Ship - Left Ctrl | Right Ctrl;
- Eagle Dive - Space;
- Pause / Un-Pause - P | Esc;

## PowerUps

- Eagle Dive - Jump and Avoid Bullets and Aliens
- Shield Power Up - Takes One Hit 
- Auto Fire Power Up - Fire every 0.1 seconds for 10 seconds
- Speed Boost Power Up - Triple Speed for 10 seconds
